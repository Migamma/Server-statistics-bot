# Server statistics bot

Бот в телеграмме для просмотра статистики на сервере 
## Для чего нужен

Server statistics bot  помогает просмотривать статистику на сервере с помощью месенджера телеграмм

## Что умеет?

 -  получение данных по Диску
 -  получение данных по трафику сети
 -  получение данных по ОЗУ
 -  получение логов из journalctl
 -  Просмотр загруженности процессора

## Как запустить

1.  Создать своего бота в телеграмме

2.  Ввести свой id и токен в код

3.  Установите зависимости:

```bash
pip install -r requirements.txt
```
4. Запустить бота:
```bash
python bot.py
```

## Технологии

-  Python — язык программирования
-  pyTelegramBotAPI - библиотека для создания телеграмм бота
- psutil - библиотека для  получения информации в системе
